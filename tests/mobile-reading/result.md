## 已實作

1. 圖片手勢：只接受主圖區明確水平單指滑動。文章文字區、縮圖列、按鈕與連結不觸發切圖；垂直／斜向閱讀、多指及取消事件不誤切換。
2. 開啟文章明確將modalBody.scrollTop設0，避免不同文章沿用舊捲動位置。跨文章閱讀位置記憶尚未導入。
3. 639px以下：預設內文1rem（一般設定為16px）、1.85行距；長標籤限制高度且可捲動，不擠壓右側控制。
4. 關閉／放大／換圖及底部操作目標44px，底部整理成兩列；動態視窗高度、safe-area邊界、內文min-height:0與不縮小的頁首頁尾。
5. 圖片放大區新增專用「結束圖片放大」按鈕，切換aria-pressed，計數器避開退出按鈕；放大時焦點移至退出按鈕，退出後回到放大按鈕，避免焦點留在隱藏元件。這是圖片容器放大，不宣稱使用瀏覽器原生Fullscreen API。

保留既有品牌色、文章內容、路由、分享、收藏及管理員流程。Firebase設定、ADMIN_UID、Rules、Authentication、Firestore、上傳與Cloudinary素材未更改。

## 驗證與限制

check.cjs：18項本地事件／鍵盤／圖片控制檢查與內嵌語法通過。涵蓋左右滑動、垂直／斜向、文字／縮圖／按鈕區、多指、觸點識別、取消、重複結束、鍵盤左右鍵、放大退出與aria-pressed。測試使用模擬事件與DOM物件，不等同實際手機手勢、CSS排版、原生捏合縮放或螢幕閱讀器驗證。

瀏覽器工具仍因本機sandbox啟動錯誤不可用。尚未取得候選截圖，不宣稱畫面測試PASS。不合併未經預覽驗證的UX候選。手機實機測試依既有使用者指示暫緩，並未被新需求自動撤銷。

候選預覽檢查清單：320/375/414px及桌機、深淺模式、長標籤、底部兩列不溢出、內文捲動、文字區不切圖、縮圖列保留橫捲、主圖左右切換、放大後退出、單圖文章、不同文章回頂、Escape及關閉後焦點。可先使用Chrome手機模擬，不把模擬結果等同實機證據。

44px採W3C較高等級的觸控目標建議，並非宣稱全站符合WCAG AAA：[W3C Target Size Enhanced](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html)。動態視窗／安全邊界使用原生CSS：[MDN env](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/env)。
